# Game fonts

IBM Plex Sans (400, 600), IBM Plex Mono (600) and Bricolage Grotesque (800),
Latin and Latin Extended subsets, from Fontsource (the Google Fonts files).
All are under the SIL Open Font License 1.1, which allows bundling them in the game.

They are bundled because a web browser cannot give the game the device's own
fonts: without these files the web version used Godot's small built-in font.
