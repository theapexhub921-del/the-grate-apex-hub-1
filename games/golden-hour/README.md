# Golden Hour (Godot 4.7)

Nursing skills game. Six night shifts, each: Learn → Drill → Prove (3D ward) → Do it for real.

- Play: open `project.godot` in Godot and press F5.
- Edit shift content (learn cards, drill questions, checklists): `data/shifts.json`.
- Edit the 3D ward scenarios for shifts 2-6 (tasks, choices, penalties, furniture): `data/wards.json`.
  Shift 1's vital-signs scenario is in `scripts/screens/prove_screen.gd`.
- Progress saves automatically on the device.
